# TechBoho TaskFlow Features

## Project Goal
TechBoho TaskFlow is a full-stack task management system that helps users organize daily tasks, track progress, manage deadlines, and improve productivity.

## MVP Features

### 1. User Authentication
- User can register an account
- User can login securely
- User can logout
- User data is protected using JWT authentication

### 2. Task Management
- User can create a task
- User can view all tasks
- User can update a task
- User can delete a task
- User can mark a task as completed

### 3. Task Details
Each task will have:
- Title
- Description
- Priority: Low, Medium, High
- Status: Pending, In Progress, Completed
- Due Date
- Created Date

### 4. Dashboard
- Show total tasks
- Show completed tasks
- Show pending tasks
- Show overdue tasks

### 5. Filtering and Searching
- Filter tasks by status
- Filter tasks by priority
- Search tasks by title

## Future Features
